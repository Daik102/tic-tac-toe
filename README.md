<h1>Project: Tic Tac Toe</h1>
A Tic Tac Toe app with several features.
<br>
This project is based on <a href="https://www.theodinproject.com/">The Odin Project</a>.

<h3>Features</h3>

- Object-Oriented data model using factory function

- Smart algorithm for Robot mode

- Keyboard support

- Responsive Design implemented

<h3>Tech Stack</h3>

- Frontend: HTML CSS JavaScript

- Icons: <a href="https://pictogrammers.com/">Pictogrammers</a>
